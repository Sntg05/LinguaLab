# Maquetas de diseño (decisión D5)

Tres direcciones para que el dueño elija antes de aplicar nada al sitio. Son HTML
estático que se abre directo en el navegador (`docs/design/maquetas/a-carta.html`) y
usa las fuentes ya instaladas en `node_modules`. No se publican.

| Maqueta | Idea | Lo que la hace propia |
|---|---|---|
| A, Carta AFI | El catálogo es una carta como la del AFI | Filas por área, columnas por tarea; las celdas vacías dicen lo que el sitio todavía no hace |
| B, Espectrograma | La portada es un espectrograma | Los tres colores de Praat (formantes, tono, intensidad) son el sistema de color de todo el sitio; el catálogo es un TextGrid |
| C, Glosa interlineal | Los títulos son glosas de Leipzig | Palabra, glosa y traducción alineadas; cada herramienta enseña con pasos numerados |

Todas: contraste AA, foco visible y sin desborde a 390 px (comprobado con Playwright).
