# Muestras de audio IPA — LinguaLab

Todos los archivos de `audio/ipa/` deben ser de **licencia libre** y estar
atribuidos aquí. Esta página es un guardrail de integridad de datos:
las descargas y reproduciciones muestran esta atribución obligatoria.

## Requisitos por archivo

| Requisito | Valor |
|---|---|
| Formato | `.wav` o `.ogg` |
| Frecuencia de muestreo | 44.1 kHz o 48 kHz |
| Duración | 0.3 – 2 s por símbolo |
| Licencia admitida | CC0, CC BY, CC BY-SA, dominio público |
| **No admitido** | CC BY-NC, CC BY-NC-SA, código propietario |

## Fuentes recomendadas (verificadas por licencia)

1. **Wikimedia Commons — *International Phonetic Alphabet***
   https://commons.wikimedia.org/wiki/Category:International_Phonetic_Alphabet_audio
   Mayoría CC BY-SA 3.0 / CC0. Revisar la ficha de cada archivo.

2. **Wikipedia (grabaciones de hablantes nativos)**
   Muchos artículos del AFI enlazan muestras en Ogg con licencia libre
   (CC BY-SA). Verificar ficha individual antes de copiar.

3. **X-SAMPA / IPA association samples**
   Algunas tablas enlazan muestras libres; comprobar autoría.

4. **Generación propia**
   Si no existe archivo, LinguaLab usa la **Web Speech API** del navegador
   (síntesis local, sin envío de datos) como respaldo automático.
